# Publicação e conclusão da E3

Repositório público: https://github.com/odavidmarinho/perboni-flv-e3

## O que foi preparado

Site de cinco páginas, documentação, guia do grupo e evidências das 93 verificações. O repositório foi criado pela conta `odavidmarinho`, autenticada no navegador pelo solicitante. Os arquivos são enviados pelo navegador porque o Git local não tinha autenticação e o conector estava vinculado a outra conta. Não foram copiadas credenciais entre as conexões.

Os commits públicos de envio pertencem à conta do solicitante. O bundle entregue preserva separadamente os commits locais de implementação. Não atribua os envios aos colegas nem considere cumprida a exigência de commits dos quatro integrantes antes das contribuições reais.

## Agora: participação do grupo

1. Envie o link do repositório e `GUIA-GRUPO.txt` aos colegas. O ZIP é uma alternativa para baixar o site; não precisam do bundle.
2. Convide as contas corretas em **Settings → Collaborators → Add people**. Como alternativa, os colegas podem usar Fork e abrir Pull Request sem convite.
3. Cada colega executa sua revisão de verdade, cria `revisoes/seu-nome.md` pela própria conta e abre um Pull Request. O guia distribui os cenários e explica os cliques.
4. Revise os resultados, resolva problemas encontrados e mescle com **Create a merge commit**, preservando os commits individuais.
5. Confirme no histórico que os quatro integrantes aparecem como autores de contribuições reais.

## ZIP final para o professor

Depois de mesclar todas as contribuições, selecione a branch **main** na página do repositório e clique **Code → Download ZIP**. Esse arquivo contém a mesma versão pública, incluindo as revisões dos colegas.

Entregue o link público e esse ZIP final. O ZIP preparado antes das contribuições não contém as alterações futuras do grupo.

## Executar e testar

Siga o `README.md`. O site não precisa de instalação de dependências para funcionar. Caso o código seja alterado, repita os testes e atualize a documentação/evidências correspondentes.

## GitHub Pages opcional

A exigência identificada no print é repositório público mais ZIP. Para hospedar o site também: **Settings → Pages → Deploy from a branch → main → /(root) → Save**. Aguarde o GitHub informar o sucesso e use o endereço exibido. Não é necessário build. Caminhos relativos permitem hospedagem em subdiretório.

## Usar o bundle local, se necessário

O arquivo `PerboniFLV-E3.git.bundle`, entregue separadamente, pode ser clonado com `git clone PerboniFLV-E3.git.bundle PerboniFLV-E3`. Ele registra o histórico local preparado pelo assistente sob a identidade Git já configurada do solicitante. Não faça force-push para substituir contribuições públicas. Para trabalhar normalmente com a equipe, clone o repositório público.
