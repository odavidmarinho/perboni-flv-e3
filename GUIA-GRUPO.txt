1. Link do repositório público: https://github.com/odavidmarinho/perboni-flv-e3 .
2. ZIP do projeto, como alternativa para baixar e testar.

COMO REGISTRAR A CONTRIBUIÇÃO SEM TERMINAL

1. Aceitar o convite de colaboração que David enviar pelo GitHub.
2. Entrar no repositório com sua própria conta.
3. Clicar Add file > Create new file.
4. No nome do arquivo, digitar revisoes/seu-nome.md.
5. Escrever a revisão que realmente realizou. Não colar um resultado de teste não executado.
6. Clicar Commit changes. Escrever uma mensagem clara, por exemplo: "Documenta revisão de teclado realizada por Luiz".
7. Selecionar a opção de criar uma nova branch, por exemplo revisao-luiz, e iniciar Pull Request.
8. Criar o Pull Request para David revisar. O commit fica com a autoria da conta usada.

Se não houver convite, usar Fork e depois Pull Request é uma alternativa. Evitem editar todos o mesmo arquivo simultaneamente.
